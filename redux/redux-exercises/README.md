# Redux Exercises

A practice of Redux

## Organisation

### Duration

1.5 hours

### Team

Same pairs of the previous day.

## Brief

Continue refactoring the Todo App code from the previous workshop by doing the following:

- Refactor the reducer, so that it can handle 3 additional case scenarios:
  - Filtering the todos 
  - Updating the status 
  - Updating the inputText 
- Add the corresponding action creators (3 action creators for each case scenario)
- Refactor the code so that it retrieves the new data from the store and manipulate the data using action creators and the `useDispatch` hook

This refactoring should allow you to remove all the states within `App.jsx` and most of the props throughout the project.
