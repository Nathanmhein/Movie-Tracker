### Extension

For this task, use your code from the morning or use the completed code within the `redux-toolkit-completed` folder - find it [here](../redux-toolkit-completed/)

**Continue** refactoring the Todo App code from the morning by doing the following:
- Refactor the reducer using Redux toolkit, so that it can handle 3 additional case scenarios:
  - Filtering the todos 
  - Updating the status 
  - Updating the inputText 
- Refactor the code so that it retrieves the new data from the store and manipulate the data using action creators and the `useDispatch` hook

This refactoring should allow you to remove all the states within `App.jsx` and most of the props throughout the project.
