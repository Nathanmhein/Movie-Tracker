# React End to end project Exercises

Practice of all concepts covered during the Deep Dive by extending on the app built with trainers.

## Organisation

### Duration

Afternoon

Make sure to take breaks!

### Team

Individually / pairs

## Brief

Apply the following extensions. The first three extensions are the priority. The rest can be tackled **ONLY** if you are done with the first three extensions.

### Extensions

- Make the app more component driven by creating an isolated component for the form itself
- Add a filtering functionality to sort tv shows by rating on the `SearchPage` - note that you might have to add another component for it too
- Implement another context within the app 
- Implement testing
- Build your own film API backend and the following requests:
    - `POST` request
    - `GET` request
    - `PATCH` request
    - `DELETE` request
    
    Then, refactor your frontend film app to use this API and you can build these additional functionalities:
    - Add a page where users can add movies to the database using a `POST` fetch request
    - Add a functionality where users can delete or edit the information of a movie using a `DELETE` / `PATCH` requests
