Group Project

## Duration

This is a one-day project.

You have until **4pm** to complete and submit your project.

## Team setup

The project will be completed by the group working collaboratively.

## What?

Your task is to build a frontend application of your choice using a third-party API. The application should include multiple components, Redux state management, routing, and several pages.

You can create anything that inspires you, as long as it can be realistically completed within one day.

The goal of this project is to build a React application using the concepts you have learned so far:

- TypeScript
- React state and hooks, including `useEffect` and `useState`
- Redux for state management
- React navigation and routing
- React component structure and props
- UX methodologies
- HTML and CSS
- End-to-end testing with Playwright

Here are some examples of applications that could realistically be built within one day:

- A recipe finder
- A weather app
- A habit tracker
- An expense tracker
- A movie database

You can be creative, but keep the limited time-frame in mind when planning your project.

This task is focused on the frontend. You do not need to implement a backend.

## How?

- Google is your first resort if you get stuck. You can then ask your peers and finally ask the teaching team if you still need help.
- Create and host your project on GitHub.
- Use TypeScript throughout the application.
- Use Redux for state management.
- Add Playwright tests covering the most important user journeys and functionality.
- Your repository should have an informative and structured README that explains:
  - The purpose of the application
  - The technologies used
  - How to install and run the application
  - How to run the Playwright tests
  - Any required environment variables or setup instructions
- Use effective group collaboration practices. Make sure tasks are divided clearly and that everyone contributes to the project.
- You can use Live Share in VS Code to collaborate.
- Ideally, deploy your project to Render to showcase it to the rest of the class.
- At the end of the day, you will showcase your project by showing the application's user journey. You do not need to prepare a formal presentation.

## Guidance

- Begin by brainstorming and choose an application that can be completed within one day.
- Define the minimum viable product before starting development.
- Think about potentially having a Dev and Testing team
- Break the project into small tasks and assign responsibilities across the group.
- Create a GitHub repository and ensure all group members can contribute.
- Sketch or discuss the interface before writing the application.
- Decide which parts of the application should become reusable components.
- Plan the key user journeys that your Playwright tests will cover.
- Prioritise core functionality over additional features.
- Make sure to take breaks, stay hydrated and stretch throughout the day.

## Deliverables

By **4pm**, your group must submit:

- A completed MVP React application written in TypeScript
- Redux state management
- Playwright tests covering the main user journeys
- A structured README
- A GitHub repositories for the project and the Playwright tests

**Optional:**

- A deployed link to your React application
