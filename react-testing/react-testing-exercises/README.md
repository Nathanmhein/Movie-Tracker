# React Testing Exercises

A practice of React Testing

## Organisation

### Duration

2 hours

### Team

Same pairs of the previous day.

## Brief

### Exercise #1

Create comprehensive tests for the end to end project built in class, using the below requirements.

Requirements are:
- Test a component that uses `useContext`
- Test a component within the Router
- Test a component containing interactivity
- Test a component requiring mocking of some sort

### Exercise #2

Create comprehensive tests for your music app, using the same requirements above

## Output

### Exercise #1

Make sure to create a new branch in your end to end repository and push your changes from the exercise

### Exercise #2

Make sure to create a new branch in your music repo and push your changes from the exercise
