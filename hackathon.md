# SED Hackathon: Superheroes 🦹

> **But… what is a Hackathon?**
- Hacking is **creative problem solving**
- A hackathon is any event of any duration where people come together to **solve problems**
- Don’t expect to have actually solved a problem by the end of the hackathon. **Real life problems are hard!** Think of the hackathon as a pit-stop on a long journey to solve problems or as a training session to practice your **problem solving skills**

### Duration

This is a half-day hackathon! 

### Team setup

Individually 

### What?

All of us have a **favorite superhero** that has inspired us at some point and made us want to be superheroes ourselves.

This is your chance to build a **frontend application** about your favorite superheroes! 

The goal of this hackathon is to build a **Superhero-themed React App** using the [Superhero API](https://www.superheroapi.com/) and all the concepts you have learned so far: 

- **React state and hooks** (useEffect, useState)
- **React state management** (useContext)
- **React navigation**
- **React project structure**
- **UX methodologies**

**PLEASE NOTE** that the provided Superhero API requires an access token in order to get the data. You will need to spin up an access token using your Github account and use that token in the URL. 

This task is focused **on the front-end only**; you don't need to implement any kind of back-end.

There is no limits or requirements for this hackathon. The only requirement is to make use of the [Superhero API](https://www.superheroapi.com/). Whether you’d like to build a dating app for superheroes, a memory game about superheroes, or an interactive search app to learn about superheroes, the choice is yours and you can be as creative as you’d like to be. 

**Please make sure to write a structured README, explaining the theme and purpose of your application.**

### Extensions

- Make it responsive!
- Make it pretty!

### How?

- Google is your friend! If you get stuck on anything, your first resort should be google, then you can ask your peers, and finally come to us if none of the previous solutions helped you
- Make sure to host your project on **Github**
- Your repo should have an informative and structured **README** that includes how to run the application and any other setup instructions. See our [Writing READMEs guide](https://github.com/getfutureproof/fp_guides_wiki/wiki/Writing-READMEs) for details.

### Guidance

- Take time to brainstorm and choose the kind of superhero-themed app you’d like to build 🧠
- Build a design diagram to understand the structure of your React app 🗣️
- Create a Github repository for your project 📁
- Start by designing the interface for your project using your UX skills 🗓️
- Think carefully about what should be turned into a component 💻
- Make sure to take breaks, hydrate and stretch 💧

### Deliverables

No deliverables. This is mainly for your own practice. However, if you'd like to share the Github repo or a deployed version of the website, feel free to do so!
